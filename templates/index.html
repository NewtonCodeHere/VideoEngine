REST API REFERENCE · HIGH PERFORMANCE ENDPOINTS

VideoEngine Developer Hub

Integrate automated document-to-video capabilities into any microservice or enterprise pipeline with standard REST endpoints.

FastAPI Interactive OpenAPI Specifications

Access Swagger UI or ReDoc schema viewers directly.

🚀 Open Swagger UI 📖 Open ReDoc
POST /api/v1/pdf/extract
Ingest PDF and return extracted text structure

Uploads a multipart PDF file and returns structured page-level text, headings, and character counts.

curl -X POST "http://localhost:8000/api/v1/pdf/extract" \ -H "accept: application/json" \ -F "file=@document.pdf" \ -F "use_ocr=false"
POST /api/v1/pdf/script
Synthesize multi-scene script from corpus

Converts raw documentation into formatted visual scene paragraphs with timing and keyword estimations.

curl -X POST "http://localhost:8000/api/v1/pdf/script" \ -H "Content-Type: application/json" \ -d '{"full_text": "...", "duration": "medium", "style": "documentary", "language": "en"}'
POST /api/v1/broll/jobs
Submit asynchronous video rendering pipeline job

Enqueues a background video job supporting PDF, direct script, or raw audio inputs.

curl -X POST "http://localhost:8000/api/v1/broll/jobs" \ -F "input_mode=pdf" \ -F "pdf_file=@document.pdf" \ -F "aspect_ratio=16:9" \ -F "captions=true"
GET /api/v1/jobs/{job_id}
Poll execution status & retrieve deliverables

Returns job status (queued, running, succeeded, failed), progress percentage, and URLs for MP4, SRT, and manifest files.

curl -X GET "http://localhost:8000/api/v1/jobs/df521158-aaa8-40d9-b095-7c47dba6e183"
GET /ready
Readiness probe & system capabilities check

Checks database availability, upload storage, and FFmpeg / Mock render engine state.

curl -X GET "http://localhost:8000/ready"
